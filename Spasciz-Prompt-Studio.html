Step 02 · Account & credit

Create Your Anthropic Account

This is the account that powers your generations. Free to create.

  • 1
    Open the Claude Console (platform.claude.com) and sign up with your email.
  • 2
    Verify your email and log in.
  • 3
    Go to Settings → Billing. New accounts get a small amount of free credit to test with.
  • 4
    When that runs out, add a card and load $5. On the recommended model that covers well over 100 vocal scripts.
Open Anthropic Billing ↗
Heads up: API credit is separate from a Claude.ai Pro subscription. Having Claude Pro does not give you API credit — you need credit on the Console side.

Set Up OpenAI API Billing

Use the OpenAI Platform — the developer side of OpenAI. Your ChatGPT login works there too.

  • 1
    Open the OpenAI Platform and sign in, or sign up with your email.
  • 2
    Go to Settings → Billing and add a payment method.
  • 3
    Add prepaid credit. $5 goes a long way — roughly 125+ generations.
Open OpenAI Billing ↗
Heads up: a ChatGPT Plus or Pro subscription does not include API credit. API usage is billed separately on the Platform, so you need credit there even if you pay for ChatGPT.

Step 03 · Generate the key

Create Your API Key

One key is all you need. It works until you delete it.

  • 1
    Open Settings → API Keys in the Console.
  • 2
    Click Create Key. Name it something you'll recognize — "Prompt Studio" works.
  • 3
    Copy it immediately. Anthropic shows the full key exactly once. If you close the dialog without copying, just delete it and make another.
Open API Keys ↗
Your key starts with sk-ant- and is a long string of characters. Treat it like a password — anyone with it can spend your credit.
  • 1
    Open API keys in the OpenAI Platform.
  • 2
    Click Create new secret key, name it "Prompt Studio", and leave Permissions on All — restricted keys can block the models Prompt Studio needs.
  • 3
    Copy it immediately. OpenAI shows the full key exactly once.
Open API Keys ↗
Your key starts with sk- (usually sk-proj-). Treat it like a password — anyone with it can spend your credit.
